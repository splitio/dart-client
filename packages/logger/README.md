# logger

Logging abstraction for the Split SDK: a thin `Logger` / `LogLevel` facade over `package:logging`.

## Key exports

| Type | Description |
|---|---|
| `Logger` | Logging facade used by all SDK packages |
| `LogLevel` | Severity levels (debug/info/warn/error) |

## Dependencies

**Internal:** none (leaf) · **External:** `package:logging`

## Spec reference

SDK Specification v1 — §3.1 (`logger` module).
